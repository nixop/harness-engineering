Relay architecture

Relay accepts delivery requests from product services and posts signed webhooks to customer endpoints. This page describes the runtime shape; the API is in the repository under docs/overview.md.

Runtime

relay-api (3 replicas) and relay-worker (6 replicas) run on the shared EKS cluster. Callers reach the API through the API gateway since March 2026. The system of record is DocumentDB (relay-prod-docdb, one writer, two readers).
