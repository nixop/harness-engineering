# ADR-008: Secrets from SSM Parameter Store

**Status:** Accepted
**Date:** 2026-09-09
**Author:** Yulia Tarasova
**Deciders:** Relay weekly sync, 2026-09-07

## Context

On Lambda the first design kept secrets in environment variables and in CloudFormation parameters, visible to anyone with describe permissions.

## Options considered

- Environment variables encrypted with KMS
- Read from SSM Parameter Store at startup and cache in the instance (chosen)

## Decision

Secrets are read from SSM Parameter Store at startup; no secrets in Lambda environment variables or CloudFormation parameters.

## Consequences

About 100 ms added to a cold start, hidden by provisioned concurrency. Rotation becomes a parameter update plus a redeploy.
