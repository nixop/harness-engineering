Ledger architecture

Ledger is the system of record for customer charges. This page describes the deployment shape; the API is documented in the repository under docs/overview.md.

Deployment

Two replicas of ledger-api behind the nginx front (to be replaced by the Edge gateway, see ), one ledger-worker, PostgreSQL 16 with a streaming replica. The worker runs invoice generation at 02:00 and tariff recalculation at 03:00.

Data flow

ledger-flow
  1. A caller posts a charge through the gateway.
  2. ledger-api validates the tariff code against the catalogue and inserts the charge.
  3. finance-export reads yesterday's charges at 06:00 and writes a CSV keyed by the legacy tariff code to the finance warehouse.
